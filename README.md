<h3>Реализация:</h3>
Калькулятор на чистом JavaScript с использованием webpack конфига для оптимизированного кода в production. Насторен Eslint и prettier. Настроен pre-commit-hook. Husky для автоматического запуска проверки и исправления ошибок при выгрузке в git. Также выполнен запуск в прод на бесплатном хостинге.

<h3>Реализованные функции:</h3>
Функции всех кнопок на калькуляторе. Также реализован процент от числа, например: если вбивать 4-20 и на 20 поставить процент, то калькулятор возьмёт 20% от 4 и это будет второе число. Реализована смена тем калькулятора. При нажатии на кнопку выбора схемы, выезжает меню. На устройствах с широким экраном влево, с узким вверх.

<h3>Инструкция по запуску:</h3>
Скачать и распаковать zip архив репозитория. В команодной строке перейти в папку проекта с помощью 'cd ..' и прописать одну из команд:

npm run start   (запуск дев сервера приложения. Сразу откроется окно браузера с портом 5000. Можно редактировать код приложения и он будет динамически его обновлять в браузере)

npm run build:prod
npm run build:dev 
(Эти две команды соберут приложение в папку build. Там будет всего два файла, один .html и один .js . Если запустить dev, в файлах будет читаемый но не оптимизированный код, при запуске prod, будет максимально сжатый и оптимизированный код. Это и будет финальное приложение)
